# 研究笔记索引

> 状态：2026-11-24 建立。
> 适用对象：E-M10 Mark II，固件 `E120 1400 0000 0000`。
> 这些不是教程，而是**决策记录 + 失败记录 + 证据边界**。所有地址只对上述机型/版本有效，不要跨机型搬。

## 为什么有这层

EP7 / PEN-F 这类项目真正有价值的部分，不只是最终补丁，而是：

- 这条改动依据什么；
- 试过哪些路，为什么失败；
- 哪些结论后来被推翻了；
- 哪些是静态推断，哪些是真机验证；
- 后来者从哪里继续。

本项目工作区里积累了大量审计、地图和失败复盘，但发行版只保留了用户需要的结论。这里补上“研究过程”这一层，同时做脱敏。

## 发布边界

**会写：**

- 问题、假设、方法；
- 关键地址、字节、调用链；
- 真机 / 模拟 / 静态 / 推理四种证据等级；
- 失败路径、死路、被推翻的旧结论；
- 哪些结论只适用于本机型。

**不会写：**

- 官方固件本体、成品 BIN；
- 实拍照片、EXIF 里的个人信息；
- 个人路径、卡符、设备序列号；
- 商业 LUT、第三方项目全文；
- 未经验证的推断，冒充已证结论。

## 读法

- 先看每篇开头的 `Status / Evidence`；
- `静态已证` 只说明字节和分支读出来了，不说明真机行为；
- `模拟` 只说明这条路径在模拟器里执行到；
- `推理` 是尚未闭环的判断，不能当结论引用；
- 被标 `superseded` 的笔记只作历史，不要拿旧结论覆盖新结论。
