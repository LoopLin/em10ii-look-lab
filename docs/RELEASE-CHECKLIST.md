## D. 已知限制（要写进 README，不藏）

- 四档是「按参考 LUT 拟合」的近似，不是富士/柯达原厂曲线；
- 色度只有 **16 点 Cb/Cr 曲线 + 3×3 矩阵**两级可调，局部色相修正能力有限；
- i-Enhance / Natural 在原厂里成像相同（`docs/analysis/n-key-source.md`），我们对 N 档做了 1 字节 key 修复；
- ART 模式不走我们的钩子，保持原厂；
- 预览链若与成片分岔，Portrait 下 LV 可能仍偏灰（见 `docs/map/preview-chain.md`）。
