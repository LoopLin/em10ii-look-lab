## 2. 法律依据（为什么这样发是相对安全的）

1. **互操作性例外**：为让设备与他人产品互通而进行的逆向工程，在美国（Sega v. Accolade、Sony v. Connectix）与欧盟（Software Directive 2009/24/EC 第 6 条）均有明确空间。我们做的是**色彩表格式解析**，目的正是互操作（用自己的色彩曲线）。
2. **不构成规避技术措施**：本机固件**没有加密**，只有逐字节取反 + 16 字节列置换（混淆）。混淆不等于"有效控制访问的技术措施"，因此不落入 DMCA §1201 / 我国《著作权法》第 49 条。
3. **不发固件 = 不发复制件**：我们只发"改法说明"（offset + 新字节 + 旧字节哈希）。用户自己拥有固件副本并自行施加修改，属其个人使用范畴。
4. **事实与表达二分**：函数地址、表结构、数值属事实，不受版权保护；受保护的是表达（代码、文档）。因此"引用地址"安全，"整段复制代码/文档"危险。
5. **商标的指代性使用**：正文里写"参考 Ektachrome"属描述性提及，允许；但用作商品名/插件名/文件夹名不允许——发行版已全部中性化。

## 4. 残余风险与缓解

| 残余 | 说明 | 缓解 |
|---|---|---|
| **EULA 违约**（非版权） | 厂商许可条款通常禁止修改固件；这是合同问题，不是侵权 | README 写明"使用者自行承担"；不提供成品固件 |

| **导出/再分发补丁** | 他人可将其打包进固件分发 | LICENSE 明确"补丁不含固件权利"；NOTICE 第 6 条 |
