## 四、每个新钩子必须回答的四个问题（PEN-F 教训）

PEN-F 的 HSL 少挂一路 → “预览有、存下来的 JPEG 中性”。我们也踩过同类（成片对、预览不对）。
今后每个钩子交付时，`verify_*` 必须列出并检查：

1. **capture**（按快门的成片路径）
2. **preview**（EVF/显示屏每帧路径）
3. **recording**（录像路径）
4. **compact / 回放**（缩略图与回放路径）

缺哪一路，就在文档里写明"该路不生效"，不许默认"应该都一样"。
