# 22 场景验收（正式版前的最后一道）

> 目的：确认四档 look 在**真实场景**里没有塌灰、爆白、死黑、跑色，而不是只在色卡上好看。
> 前提：**卡上固件 = L55**（V/N tone 已达标，M/P 有已知偏差，见 `docs/STATUS.md` §5.x）。

按场景顺序，每个场景拍 **V → N → M → P** 各一张，构图不动、EV 0、自动白平衡、自动曝光。

## 二、怎么判（三层，先眼看后量化）

1. **眼看**：`tools/acceptance_sheet.py` 出四宫格拼图，先整体扫一遍——塌灰/爆白/死黑/跑色一眼就能看出来；
2. **量化**：`tools/compare_baseline.py <四张编号>` 出「新拍 / 原厂 / 参考 look 目标」三列，看灰阶六格残差；
3. **记档**：每个场景一行写进 `docs/analysis/acceptance-22.md`（本文件下方表格追加）。

判据（沿用 `docs/release/RELEASE-CHECKLIST.md`）：
- 灰阶每格残差 ≤ **10 码**（V/N 应 ≤6）；
- 无整片偏色（白墙/灰卡不偏）；
- 高光不整块死白、暗部不整块死黑；
- 同场景四档**能看出区别**，且区别方向符合 look 的定位。

## 四、已知限制（验收时不要重复报）

- **M 白端约 +20 码、P 暗端约 −15 码**（tone 轴已冻结，见 `docs/STATUS.md` §5.x）；
- 绿族局部色相在四档都偏（16 点色度曲线的硬上限）；
- 预览与成片色彩一致（B68 真机），但预览受显示侧 gamma 影响，观感会略平。
