## 0. 怎么读这张表

- **价值**：对"成品可用性 / 后续迭代速度"的贡献。★ = 低，★★★★★ = 高。
- **成本**：人时 + 刷机次数 + 变砖风险。刷机次数是硬成本（每次都要你亲自操作）。
- **状态**：`未开始` / `有前置` / `已就绪` / `已交付` / `已冻结`。
- 组合原则：**先去掉"每次都要刷机"这个结构性成本**，其余都变便宜。
